# Icons8 file-format icons

These 96 px PNG assets come from Icons8's Color icon family and are used by the
tool catalog. They are static designer-made icons; no generative image tooling
was used.

Source references:

- PDF: https://icons8.com/icon/13593/pdf
- Word: https://icons8.com/icon/13624/word-file
- XLS: https://icons8.com/icon/13425/xls
- PPT: https://icons8.com/icon/19670/ppt
- File-format collection: https://icons8.com/icons/set/document-format
- Icons8 license and attribution: https://icons8.com/license

Icons8's free license requires a link back to Icons8. The application includes
that attribution in the persistent sidebar and site footer. If the project uses
a paid Icons8 license, retain the source references for asset provenance even
if the visible attribution is no longer required.
